### [AWS releases official Rust emulator for local service testing](https://simonwillison.net/2026/Nov/11/aws-emulator/) ⭐️ 8.0/10

AWS has published aws-emulator, an official emulator that lets developers run tests against local clones of its many services without provisioning a paid API key. The tool is written in Rust and was built by a large swarm of AI agents, producing 29,684 commits in the project&\#x27;s first three weeks. Swaminathan \(Swami\) Sivasubramanian wrote about how it came to be in a guest post on Werner Vogels&\#x27; blog. Running it on macOS or Windows currently requires Docker, which limits its use in standard test suites; Simon Willison said he hopes AWS will eventually provide a single downloadable binary that works across languages and platforms.

rss · Simon Willison · Nov 11, 21:18

**「Background」** Normally, testing code against AWS means provisioning cloud resources and supplying credentials, which adds cost and setup overhead. AWS Emulator, hosted in the official aws GitHub organization, provides a local copy of more than 200 AWS services that developers can point their AWS SDK at; its documentation states that the emulator itself carries no additional service fee, though deployed AWS resources are still billed. It was launched in November 2026 and, according to AWS&\#x27;s announcement, was written and tested entirely by AI agents.

**「Impact」** Developers can build and test against local AWS service clones without paid API keys or additional service fees, though macOS and Windows users must run it through Docker and it is explicitly not for production or security testing.

### [UMAP 0.6 ships recursive initialization and faster, scalable optimizers](https://www.reddit.com/r/MachineLearning/comments/1xudaah/umap_06_new_initialization_new_optimizers_and/) ⭐️ 8.0/10

UMAP 0.6 has been released with a new recursive initialization, redesigned optimizers, and faster PyNNDescent-backed nearest-neighbor search. On 3 million arXiv papers, the release finishes in under 5 minutes, compared with 52 minutes for a seeded UMAP 0.5 run that is single-threaded, a roughly 12x difference; UMAP 0.6 can also run reproducibly with a fixed seed while using every core. The author reports that the new initialization lays out a coarse graph and refines it recursively, reaching within 3% of the final layout in fewer epochs than spectral initialization or PCA, while hard-negative mining and better handling of high repulsion strengths improve kNN recall and resolve finer cluster structure at million scale. The new initialization and optimizers are opt-in because they change output, enabled with compatibility\_layout=False, and future versions are planned to make them the default; installation is via pip install -U umap-learn or conda-forge.

reddit · r/MachineLearning · /u/lmcinnes · Nov 12, 13:51

**「Background」** UMAP \(Uniform Manifold Approximation and Projection\) is a nonlinear dimensionality reduction technique introduced by Leland McInnes and James Healy in 2018 in arXiv paper 1802.03426 and implemented in the open-source lmcinnes/umap library. It constructs a low-dimensional embedding that approximates manifold structure in high-dimensional data and is commonly used as a general-purpose reduction step before other machine-learning tasks. Version 0.6 changes UMAP&\#x27;s initialization and optimization stages, which are central to how the algorithm produces an embedding.

**「Impact」** Users running seeded, large-scale UMAP embeddings should see substantially shorter runtimes and finer cluster resolution, but must opt in with compatibility\_layout=False and expect different layouts from UMAP 0.5.

### [Google launches Gemini Decisions API with multimodal inputs](https://simonwillison.net/2026/Nov/11/gemini-decisions-api/) ⭐️ 7.0/10

Google has launched the Gemini Decisions API and its Gemini Decision 1 model, entering a decision-model category already occupied by Jev and OpenAI. The API supports the same three question types as Jev—yes/no, choice, and rubric scoring—and reuses Jev&\#x27;s &quot;Noul&quot; term for yes/no questions. Pricing matches OpenAI&\#x27;s GPT-6 Luna decision model at 10 cents per million input tokens with free output, while Jev remains cheapest at 4.2 cents per million. Gemini Decision 1 accepts text, images, audio, video, and PDFs, whereas Jev is text and JSON only and OpenAI handles text and images. In a video test, it returned yes/no answers as probabilities—0.923 for robot and USA, 0.0498 for dragon, and 0.0833 for France—rather than the 1.0 or 0.0 values Jev and OpenAI return.

rss · Simon Willison · Nov 11, 22:03

**「Background」** Decision models are APIs designed to answer constrained questions—yes/no, multiple choice, or rubric scoring—rather than generate free-form text. Jev and OpenAI previously offered such models with different input modalities and prices. Gemini&\#x27;s entry extends that format to audio, video, and PDF inputs.

**「Impact」** Developers who need structured decisions over video, audio, or PDFs can now use a Google option at the same input price as OpenAI&\#x27;s GPT-6 Luna model, though Jev remains cheaper for text-only workloads.
