### [F-Droid 2.0 Overhaul Brings Redesigned UI and FPE Phaseout](https://f-droid.org/2026/09/24/f-droid-2.0-a-new-chapter-for-android-freedom.html) ⭐️ 8.0/10

The F-Droid project&\#x27;s September 24, 2026 announcement introduces F-Droid 2.0, a major overhaul of the open-source Android app repository that features a redesigned user interface and the phaseout of FPE. The release matters because F-Droid is a widely used distribution channel for free and open-source Android apps, and the changes aim to address longstanding usability complaints and the difficulty of configuring the privileged extension. However, the supplied source content is unavailable, so exact technical details such as versioning, migration steps, compatibility constraints, and FPE replacement mechanics remain unconfirmed.

hackernews · daveoc64 · Sep 24, 15:26 · [Discussion](https://news.ycombinator.com/item?id=49831968)

**「Background」** F-Droid is a long-running free and open-source app repository and Android client that distributes APKs built from publicly auditable source code. Older versions could use the optional F-Droid Privileged Extension \(FPE\), which required elevated privileges to enable unattended app installation and updates. F-Droid 2.0 is a complete redesign of the official client, and it does not currently support FPE, instead focusing on full-featured support for Android&\#x27;s &quot;session&quot; installer; one report also notes that it drops support for Android 6 devices.

**「Impact」** F-Droid 2.0&\#x27;s overhaul arrives as Google&\#x27;s mandatory developer verification program — requiring apps on certified devices in Brazil, Indonesia, Singapore, and Thailand to be tied to a verified developer starting September 2026, with wider global rollout from 2027 — threatens the sideloading and alternative-distribution model that F-Droid and its users depend on.

**「Community Discussion」** Commenters largely welcomed the overhaul, with one longtime GrapheneOS user saying they had switched to Droid-ify because F-Droid&\#x27;s UI was terrible and the privileged extension was painful to configure, and expressing relief that FPE is being phased out. Others raised practical concerns: a screenshot typo or line-break in the redesign, uncertainty about F-Droid&\#x27;s future amid Google&\#x27;s platform lockdown next year, a request for a user-friendly FOSS ebook reader, and a wish for a desktop F-Droid client that installs apps over adb.
